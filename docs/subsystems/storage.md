# 存储与查询

## 状态

已实现 SQLite/FTS5 快照存储、搜索、证据读取与受限邻接。

## 职责与范围

拥有持久化及查询语义；不负责模型推理与 HTTP 错误呈现。

## 接口与依赖

[IndexStore](../../apps/api/app/storage.py) 供服务层调用；底层依赖 SQLite/FTS5。

## 数据与生命周期

数据按 index_id 隔离，证据读取保存文本；写入事务维持完整性，连接由调用方管理生命周期。

## 错误与限制

邻接只遍历静态边；查询受数量和时间预算约束，冲突及失败不能留下半套数据。

## 验证

apps/api/tests/test_storage.py 验证重开数据库、事务、旧快照和查询预算。
