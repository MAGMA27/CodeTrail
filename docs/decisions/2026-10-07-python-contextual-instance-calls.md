# 决策：Python 实例字段条件调用

Status: implemented

## 问题

同一类同时存在正常构造与绕过初始化来源，不能仅凭正常构造点给通用 self 字段调用添加无条件静态边；项目功能链仍需展示可核对的初始构造关联。

## 决定

独立 ContextualCall 绑定实际 calls 激活边、同快照符号与四处源码位置。正常构造只证明该接收者的一跳初始字段绑定；普通属性容器逃逸标明后续改写未知，未知修改、别名、多义构造和闭包保守拒绝。记录单独持久化、查询和展示，不进入 static_edges、静态影响或概览可达性；共享现有查询预算。关系语义 v7、索引身份 v11，facts v4 继续复用；旧不可变快照不重写。

唯一捕获 package 根可提供短名绝对导入别名；canonical 优先，多义拒绝，不依赖运行环境或执行仓库。实现语义由 [索引](../../apps/api/indexing.md)、[存储](../../apps/api/storage.md)、[MCP](../../apps/api/mcp.md) 和 [工作台](../../apps/web/workbench.md) 维护。

## 替代方案

去掉绕过初始化保护会制造确定边；排除测试或按本项目类名白名单会掩盖来源缺口。完整数据流/运行时追踪超出当前有界静态分析范围。
